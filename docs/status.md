# 当前状态与已知问题

此页区分代码能力、验证范围和待解决问题。不是生产承诺。默认值、版本与接口以[代码事实参考](reference.md)为准；测试结果以本次实际运行输出为准，不在各文档重复维护“最新通过数”。

## 已实现

- 默认研究模式与可关闭的基础模式；多源结构化规划、独立来源有限并发、局部成功保留。
- 四项取证与四项规则 `@tool`；初搜/补搜/回读、输出结构、自适应重试、概率证据/答案检查共用有审计上下文的调用入口。
- 知识文件增量同步、可选轮询；新闻查询全分页、完整候选留档及加权排序，按正文预算获取优先文章。权重不是客观热度，未取完会明确标记。
- 版本化新闻原文、分段阅读成果、精确引用位置；严格任务键复用、FTS5 + 向量召回、可修复投影。
- 有限阅读/专题任务池，进程内模型与网络限流、租约、取消和过期结果提交防护。
- CLI 持久化检查点与研究运行管理；补搜、答案重写、双维评审、通过答案缓存。
- CLI 逐调用/逐步骤的真实输入与生成 token、重试累计、预热单列、持久研究历史账本；缺失计数与思考细分明确标注，不用估算冒充实测。
- 单调时钟逐步骤/逐执行计时；模型请求耗时与墙钟时间分开，研究恢复/程序累计不重复计历史或计入输入等待；旧记录缺失标未知。
- 默认数字化精简日志，`-v` 展开详情；中断诊断显示已保存结果、实际取证数与停止原因。恢复同时检查 next/tasks，避免节点结果已保存但图尚待推进时误判完成。
- 交互输入默认空闲 300 秒退出；正常问答退出路径尝试通知 Ollama 卸载模型，不对正在执行的研究设置 300 秒截止时间。
- 精读前结构化筛选、待确认材料保留、实体词过滤长期记忆；保留/排除理由在终端与研究事件中可核对。
- 预测的时间、统计口径、反向证据、价格基准、因果传导逐项 C 编号核验；程序阻止遗漏或未解决项目被 accept 标记放行。
- 工具继承图上下文，修复补搜自定义流的 `checkpoint_ns` 异常；分段阅读六项上限及超限限制说明。
- 本机支持思考的模型已开启思考；指纹包含开关，旧研究留档。最后独立展示本题总计和程序累计（含预热）。
- 检查模型停止原因，拒绝半截 JSON/答案并记录消耗；统一重试工具可按失败类型有界调整输出、上下文、超时和思考开关。阅读截断优先二分一次，子段仍截断即停止并持久标记，后续批次不自动重跑。

## 适用边界

- 本地单用户展示项目，无网页前端、跨问题聊天记忆、多租户权限、完整安全沙箱或分布式队列。
- 工具为程序受控执行，不是自由 ReAct；公开网络只用搜索摘要，不能声称已读完整研报。
- 研究记忆只覆盖实际抓取/读过的新闻；API 条件召回与摘要向量排序可能漏掉关键文章。
- 限流是进程内的，GPU 是否真正并行取决于服务；外部模型计算不保证严格一次。
- 字符预算不是精确 token 预算；所有提示与专题建议的总长度还需治理。
- token 统计是观测，不是端到端硬预算；Ollama 未报告的思考/输出细分、服务失败和强杀时缺失用量不能还原。嵌入与独立评估脚本不包含在 CLI 对话模型统计中。
- 知识索引重建不是原子切换；监听跨进程无写锁；嵌入距离等有库默认依赖。
- 数据库、原文版本和事件没有自动归档清理；模型同名换权重可通过摘要区分，但嵌入同路径换权重需版本化配置。
- 现有评审会误判。通过核验、流程完整阅读、测试全绿，都不能证明预测准确或报道真实。
- C 编号检查保证覆盖流程，不保证模型的每项语义判定正确；实体字面过滤也可能漏召回间接因素。思考模式通常更慢，不能承诺开启后所有判断都正确。
