# 使用 RAGAS 评估 RAG 系统

RAGAS（Retrieval-Augmented Generation Assessment，检索增强生成评估）是一个开源框架，无需大规模人工标注数据集即可评估 RAG 流程。它使用大语言模型担任裁判，对系统的不同方面进行评分，因此裁判模型的质量非常重要：小模型给出的分数通常比大模型更不稳定。

## 核心指标

- **忠实度（Faithfulness）**用于衡量生成的回答是否得到检索上下文的支持。它会把回答拆解成若干独立陈述，并根据上下文逐一验证。忠实度低意味着系统产生了幻觉。
- **回答相关性（Answer relevancy，也称 Response relevancy）**用于衡量回答是否真正回应了用户的问题，而不考虑其正确性。计算方法是根据回答生成合成问题，再比较这些问题与原始问题的向量嵌入。
- **上下文精确率（Context precision）**用于衡量相关文本块是否排在检索结果前列。如果检索器虽然找到了正确文档，却把它埋在大量无关内容之后，该指标就会扣分。
- **上下文召回率（Context recall）**用于衡量检索上下文是否包含生成参考答案所需的全部信息。召回率低说明摄取或检索环节存在问题，而不是生成环节的问题。

## 综合解读各项指标

不同指标能够诊断不同组件。上下文召回率低而忠实度高，意味着检索是瓶颈：模型诚实地依据不完整的证据作答。召回率高而忠实度低，意味着检索工作正常，但生成器忽略了证据。与单一的端到端准确率相比，这种问题分解能力正是 RAGAS 的主要优势。

## 构建评估数据集

RAGAS 评估需要一组带有参考答案（标准答案）的问题。一个合适的初始数据集应当涵盖：可从单个文本块回答的问题、需要综合多份文档信息的问题，以及知识库中**无法**回答的问题——以此验证系统会回答“我不知道”，而不是产生幻觉。只要精心选择 10～20 个问题，并在每次改动后持续运行评估，就能发现大多数功能回退。
