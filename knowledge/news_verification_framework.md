# 财经新闻核验与证据分级方法

## 适用范围

本方法用于核验财经新闻、公司公告相关报道、市场传闻和网络信息。目标不是仅凭文章数量判断真伪，而是明确：哪些是已经确认的事实，哪些只是某个主体的说法，哪些是分析者的推断，以及目前仍缺少哪些证据。

## 一、先拆分信息类型

阅读一条新闻时，先将内容拆成四类：

1. **可核验事实**：时间、地点、金额、数量、监管决定、合同状态、财务数据等。
2. **主体主张**：公司、管理层、政府、研究机构或匿名人士声称的内容。主张不等于已经证实的事实。
3. **分析推断**：对原因、影响、动机和未来结果的解释。
4. **观点或预测**：带有价值判断或依赖假设的结论。

回答时不要把后面三类改写成确定事实。若原始材料只说“计划”“预计”“可能”“据知情人士”，应保留这些限定词。

## 二、证据来源优先级

通常可按以下顺序寻找证据，但仍需检查文件是否真实、是否最新、是否与问题直接相关：

1. **一手正式材料**：监管披露、交易所公告、法院或政府文件、审计财报、正式合同信息、公司公告和原始数据。
2. **可具名的直接来源**：事件当事人、主管部门或能够直接接触事实的人。
3. **有编辑与更正机制的专业媒体**：尤其是能够说明消息来源并提供原始文件链接的报道。
4. **二次转述、匿名消息和研究评论**：可作为线索，但需要独立验证。
5. **社交媒体、聊天截图和无法追溯出处的内容**：不能单独作为确定性结论的依据。

“多个网站都报道了”不一定意味着存在多个独立证据。它们可能都在转载同一篇报道或引用同一个匿名来源。应追溯共同的最初来源。

## 三、核验步骤

1. **定位原始出处**：查找公告、报告、讲话全文或数据发布页，不只阅读新闻摘要。
2. **核对身份与权限**：确认发言人是否有资格代表机构，文件是否来自官方网站，账号是否为真实账号。
3. **核对时间**：区分事件发生时间、首次披露时间、报道发布时间和后续更新时间，避免把旧闻当成新消息。
4. **核对数字**：检查币种、单位、统计口径、同比或环比、名义值或实际值、预测值或已实现值。
5. **独立交叉验证**：优先寻找两个或更多彼此独立、能够直接接触事实的来源。
6. **寻找反方信息**：联系或检索涉及的各方，检查是否存在否认、更正、监管质疑或相反数据。
7. **检查利益与动机**：分析信息提供者是否持有相关资产、参与交易、从宣传中受益，或可能规避责任。
8. **标记未知项**：明确尚未披露的合同条款、执行进度、会计口径、审批条件等，不用猜测填补空白。

网络搜索结果、自动摘要和人工智能生成内容也必须经过同样的来源核验，不能因为表达流畅就视为事实。

## 四、建议的可信度标签

- **已确认**：有直接的一手材料，或多个相互独立且可靠的来源一致支持。
- **部分确认**：核心事件有证据，但金额、范围、时间或影响等关键细节仍未确认。
- **未核实**：只有单一匿名来源、二次转述或无法追溯的网络内容。
- **存在冲突**：可靠来源之间有实质矛盾，当前无法消除。
- **已被否定或更正**：原始发布者或可靠证据已经明确推翻早期说法。

可信度不是永久标签。新公告、更正或数据出现后应重新判断。

## 五、模型回答模板

```text
结论：已确认 / 部分确认 / 未核实 / 存在冲突

已确认事实：
- 事实 + 时间 + 直接来源

仍属主张或推断：
- 谁提出了什么说法
- 该说法依赖什么假设

缺失证据：
- 还需要哪份公告、数字或当事方回应

注意事项：
- 是否存在利益冲突、口径差异、旧闻重发或共同转载源
```

## 主要依据

- [Reuters Journalistic Standards](https://reutersagency.com/about/standards-values/)：强调准确性优先、具名来源、交叉核验、区分事实与传闻、披露未知项，并要求网络与人工智能生成信息接受同等核验。
