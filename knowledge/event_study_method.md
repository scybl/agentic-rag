# 事件研究法：衡量新闻与市场反应

## 适用范围与限制

事件研究法用于估计某个经济事件或信息披露在特定时间窗口内与证券价格变化的关系。常见事件包括财报发布、并购公告、监管决定、产品发布和突发事故。

它回答的是“相对于正常市场波动，事件附近是否出现异常收益”，不自动证明新闻导致了全部价格变化。若同一时期存在其他重大消息，因果归因会受到干扰。

## 一、研究设计

1. **定义事件与样本**：明确事件类型、公司范围、纳入和排除规则，避免事后只挑选符合预期的案例。
2. **确定事件时间**：记录公告的准确时间、时区和交易时段。盘后公告的第一个反应交易日通常是下一交易日。
3. **选择事件窗口**：例如 `[0, 0]`、`[-1, +1]` 或更长窗口。窗口越长，可能捕捉延迟反应，也越容易混入其他事件。
4. **选择估计窗口**：使用事件发生前、与事件窗口不重叠的一段历史数据估计正常收益关系。
5. **选择基准**：可使用宽基市场指数、行业指数或因子模型。基准应能代表该证券在没有事件时的常态波动。

窗口没有普遍适用的固定长度。信息明确、时间准确的公告通常适合短窗口；复杂、分阶段或史无前例的事件可能需要更长窗口和额外分析。

## 二、基本计算

一个简化的市场模型为：

```text
R(i,t) = α(i) + β(i) × R(m,t) + ε(i,t)
```

其中 `R(i,t)` 是证券收益率，`R(m,t)` 是市场基准收益率。用估计窗口得到 `α` 和 `β` 后，事件日异常收益为：

```text
AR(i,t) = 实际收益率 − 模型预测的正常收益率
```

事件窗口内的累计异常收益为：

```text
CAR(i; t1,t2) = Σ AR(i,t)
```

对多个事件组成的样本，可以进一步计算平均异常收益和平均累计异常收益，并进行统计显著性检验。成交量、波动率、买卖价差也可作为补充反应指标。

## 三、必须排查的干扰因素

- **重叠事件**：同期财报、宏观数据、行业政策、评级调整或诉讼消息都可能影响价格。
- **提前泄露与预期形成**：市场可能在正式公告前已经反应；公告结果还应与市场预期比较，而不只是与上一期数据比较。
- **公告时间错误**：只记录日期而忽略盘中、盘后和时区，会把反应放到错误的交易日。
- **交易不活跃**：停牌、涨跌停、低流动性和非同步交易可能扭曲收益率。
- **基准选择不当**：公司受行业因素影响较大时，仅用宽基指数可能不足。
- **样本选择与多重检验**：反复尝试窗口、模型和样本后只报告显著结果，会夸大证据。
- **新闻细节缺失**：同一个标题可能包含市场事前不知道的隐含细节，价格反应也可能来自这些未观测信息。

因此，应报告窗口、基准、样本规则、同时发生的事件、统计不确定性和稳健性检验，而不是只展示一个 CAR 数字。

## 四、适合新闻问答系统的轻量版本

当数据不足以进行严格统计研究时，可以提供一个明确标为“描述性分析”的版本：

1. 记录消息首次公开的准确时间和来源。
2. 计算证券在事件日及前后若干交易日的收益率。
3. 同期对比宽基指数和行业指数，得到粗略超额表现。
4. 检查成交量、波动率以及公告前是否已有异常反应。
5. 列出窗口内的其他重大消息和市场共同冲击。
6. 将结论写成“事件附近存在某方向的异常表现”，不要直接写成“事件导致了该涨跌”。

建议输出表：

```text
事件与时间：
市场原有预期：
事件窗口和选择理由：
证券收益 / 市场收益 / 行业收益：
粗略异常收益或 CAR：
成交量与波动变化：
同期干扰事件：
结论与置信度：
```

## 主要依据

- [MacKinlay, 1997, Event Studies in Economics and Finance](https://ideas.repec.org/a/aea/jeclit/v35y1997i1p13-39.html)：事件研究法的经典综述，说明如何用证券价格衡量经济事件对企业价值的影响及其主要复杂性。
- [NBER：Event Study Methodology](https://www.nber.org/system/files/working_papers/w15809/w15809.pdf)：短期公告效应、事件窗口选择和复杂事件研究设计的讨论。
- [NBER：Missing Events in Event Studies](https://www.nber.org/papers/w25016)：提醒研究者，标题或可观测事件并不包含市场获知的全部细节，遗漏信息会影响归因。
